# A Settled-Gate Fault-Tolerant-Control Benchmark for Spacecraft Attitude

A reproducible benchmark and leaderboard for fault-tolerant spacecraft attitude control on a settled gate: a structurally held-out actuator-fault taxonomy plus a sensor-fault regime, with a leaderboard generated directly from committed evidence so any controller can be scored on identical, honest gates.

## Reproduce

Run from the **repository root** (this folder). The package layout is preserved
so `python -m package.module` resolves directly:

```bash
pip install -r requirements.txt
python -m benchmark.leaderboard  # regenerate benchmark/leaderboard.md from evidence
python -m program.eval_taxonomy         # settled-gate battery across held-out faults
```

## Status

The leaderboard generator (`benchmark.leaderboard`) is pure NumPy and reads committed evidence (`evidence/program/taxonomy_settled.json`, `gain_bias_dob.json`, `sensor_faults.json`), so it runs from a clean checkout. The benchmark manuscript reuses the companion controller-study tables; for standalone compilation those two `tab_*.tex` files are vendored into `paper/benchmark/tables/` and the `\input` paths are rewritten to be local. Fresh battery runs need Basilisk (`pip install bsk`) + checkpoints.

### Trained checkpoints (not shipped)

Learned weights (`checkpoints/*.pt`, `checkpoints/commander_*.gguf`) are large binaries and are **not** included. Each is regenerated by its training entry point in this repo (the RMA students via the `controller.rma.*` training mains; the commander via the `commander.nl_pddl.*` training mains). The committed `evidence/*.json` files let the manuscript tables/figures reproduce **without** the weights.

### Basilisk

Fresh high-fidelity runs use the Basilisk 6-DOF simulator. Install with `pip install bsk`. Basilisk-gated code paths skip gracefully when it is absent, and the pure-NumPy reproduce commands above do not need it.
